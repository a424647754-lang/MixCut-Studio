1认识 MixCut Studio

MixCut Studio 是面向本地素材的 AI 混剪工作台。它把素材导入、镜头分析、参数配置、片段筛选、时间线生成和剪映草稿输出收在一条流程里。

1.1 它解决什么问题

核心工作不是“随机拼接”，而是先从素材中找出可用片段，再按时长、重复度、画面质量、卡点、转场和配乐规则生成一条可继续编辑的时间线，最后写入剪映草稿。人在剪映里仍然可以逐段调整。

1.2 完整流程

阶段页面你要做的事产出
准备素材库导入视频、建文件夹分类、勾选要分析的范围素材清单
检查素材预览播放原片或代理，确认画面、时长与声音预览结论
分析AI 分析选择快速、中度或严格分析，等待片段结果镜头片段与评分
配置参数设置设时长、重复度、版本、卡点、转场与配乐混剪规则
执行任务中心启动全流程，查看进度、日志与输出剪映草稿
收尾剪映打开草稿，做人工精修与导出成片

1.3 五个主页面

素材库素材预览AI 分析参数设置任务中心，设置页从顶栏齿轮进入，不占用主导航位。

1.4 名称对照

界面里的“素材分析”就是 AI 分析页；“工作台 / 素材预览”是同一个预览页；任务中心里的“写入草稿”指把生成结果写进剪映草稿目录，不是直接导出 MP4。

1.5 两种使用方式

  • 安装版：通过安装包安装，自带 Python、PySide6、FFmpeg 与所需运行库，不需要另装环境。
  • 源码 / 绿色版：在工程根直接运行，适合开发与调试；缓存和配置写在工程目录，目录不可写时回退到用户目录。
重要边界MixCut 负责生成可编辑草稿，不替代剪映的最终调色、字幕、导出。草稿生成后仍建议逐段检查。

2安装、启动与界面

2.1 安装版

  1. 运行 MixCutStudio_Setup_v1.0.0.exe。
  2. 安装程序需要管理员权限，默认安装到 C:\Program Files\MixCutStudio。
  3. 安装完成后从开始菜单或桌面图标启动 MixCutStudio.exe。
  4. 首次启动会创建缓存与配置目录；如果安装目录不可写，会自动回退到 %LOCALAPPDATA%\MixCut。

2.2 启动界面

安装版启动图从三张品牌图中随机选择一张，底部显示真实加载进度条；源码运行使用固定的品牌启动图。进度条反映初始化步骤，不是装饰动画。

2.3 主界面

  • 顶栏：工程入口、页面状态、设置齿轮和窗口控制。
  • 左侧导航：素材库、素材预览、AI 分析、参数设置、任务中心。
  • 内容区：当前页面的卡片、列表、预览器或参数表单。
  • 底部状态区：任务、日志和当前工程提示。

2.4 关闭与保存

关闭窗口前如果有未保存改动，程序会提示保存工程。工程保存的是路径和配置，不内嵌素材文件；移动素材或换机后需要保证原路径可访问。

2.5 系统要求

项目建议
系统Windows 10 / 11 64 位
内存16 GB 起，4K 多轨建议 32 GB
显卡支持 NVENC 的 NVIDIA 显卡更佳；没有也能用 CPU 编码
磁盘系统盘留出足够缓存空间，代理会额外占用磁盘
显示1920×1080 起；高 DPI 缩放由 Qt 处理
剪映已安装剪映专业版，并能正常打开草稿目录

3工程管理

3.1 新建、打开、保存

顶栏和设置页都提供工程入口。快捷键为 Ctrl+N 新建、Ctrl+O 打开、Ctrl+S 保存。

3.2 工程文件

工程文件扩展名为 .mixcut，内容是 JSON，当前版本号为 3。保存时先写临时文件，再替换正式文件，并保留 .bak 备份，降低写入中断导致工程损坏的概率。

3.3 工程里保存什么

数据是否保存说明
素材路径与列表是保存绝对路径，不复制素材文件
文件夹分类与标签是库内虚拟分类，不移动磁盘文件
素材元数据是分辨率、时长、帧率、编码等
AI 分析结果是已完成的片段与评分
混剪参数是时长、重复度、卡点、配乐等
输出配置是草稿目录与命名规则
素材视频本体否只引用原文件

3.4 换机与迁移

把工程文件和素材一起迁移，保持素材在原绝对路径；如果路径变了，先在素材库重新定位或重新导入，再继续分析和混剪。不要只拷工程文件，否则打开后会出现素材缺失。

3.5 撤销

Ctrl+Z 撤销上一步，Ctrl+Y 或 Ctrl+Shift+Z 恢复。保存工程后继续操作，再按 Ctrl+S 会更新当前工程文件。

3.6 工程异常排查

  • 打开后是空白工程：确认打开的是 .mixcut，不是旧版配置或别的 JSON。
  • 素材全部显示缺失：检查原路径是否还在，盘符是否变化。
  • 工程打不开：先用同目录的 .bak 备份替换，再逐项检查 JSON 是否被外部工具改坏。

4素材库

4.1 页面结构

素材库由文件夹分类、素材卡片列表、筛选栏和底部操作区组成。单击选中，右键打开单项菜单，勾选用于批量分析。

4.2 导入与扫描

  1. 点“导入素材”，选择一个或多个视频文件。
  2. 需要整目录导入时，选择文件夹，程序扫描其中的视频。
  3. 导入后等待元数据读取完成，再开始分析。

支持常见视频格式；具体能否解码取决于内置 FFmpeg 与系统解码能力。导入只建立引用，不复制原文件。

4.3 筛选与排序

可按文件名、时长、分辨率、分析状态筛选；排序用于快速找到最长、最短或最近导入的素材。筛选只影响当前列表显示，不改变工程数据。

4.4 文件夹分类

文件夹是库内虚拟分类。把素材放进文件夹不会移动磁盘文件，也不会删除原素材。删除文件夹时，里面的素材会回到“全部素材”。

4.5 勾选与“分析选中”

分析范围遵循一条明确规则：有勾选时只分析勾选的素材；没有勾选时退回当前文件夹；当前是“全部素材”且没有勾选时，分析全部未移除素材。

这就是“只选了一个素材，却分析了所有素材”的常见原因：勾选没有真正生效，或当前列表是“全部素材”且没有任何勾选。开始前看底部提示的“将分析 N 个素材”。

4.6 移除与删除

  • 移除：从当前素材库移除引用，不删除磁盘文件，不删除已分析片段。
  • 删除：删除库内素材记录；是否联动删除已选片段取决于当前清理动作，执行前看确认提示。
  • 删除文件夹：只删除分类，素材回到全部素材。
不会删除原片素材库里的移除、删除和分类操作都不动磁盘上的视频文件。需要彻底删除原片时，请到资源管理器手动处理。

4.7 检查素材

“检查素材”用于确认文件可读、元数据可解析。检查成功弹窗可能仍显示旧文案，但实际结果以列表状态和日志为准。

4.8 标签

标签用于人工备注和筛选。标签保存在工程内，不写入视频文件元数据。

4.9 清空后的联动

删除所有原素材和文件夹后，已选片段和对应分析结果会一起清理，避免留下无法对应原片的孤立片段。执行前请确认工程已保存。

5素材预览

5.1 播放控制

预览器支持播放/暂停、进度拖动、音量、逐帧查看和全屏。快捷键 Space 播放/暂停，P 全屏，Esc 退出全屏。

5.2 底部素材条

底部缩略图条用于切换当前素材。单击切换，当前素材的播放位置会重置；需要保留位置时先记时间码。

5.3 元信息与全屏

预览区显示分辨率、帧率、时长、编码和当前代理状态。全屏只放大预览画面，不改变输出配置。

5.4 代理下拉框

可选档位为 代理关闭、720p、960p、1280p，默认关闭。

5.5 代理的真实工作方式

  • 选择任一代理档位，会把素材库里全部视频排队生成代理，不是只代理当前这一条。
  • 当前素材代理就绪后，预览会自动换到代理源，并尽量保留播放位置。
  • 代理只影响预览。导出、草稿和最终成片仍使用原片。
  • 代理编码为 HEVC Main10、YUV420P10LE，保持原帧率，音轨为 AAC 192k。

5.6 档位选择

档位适合代价
代理关闭1080p 及以下、编码简单的素材4K 10-bit 4:2:2 容易卡顿
720p老机器、快速浏览细节损失明显
960p4K 素材的默认折中需要等待后台生成
1280p需要更清晰预览生成和播放占用更高

5.7 卡顿处理

先确认是不是 4K 10-bit 4:2:2 原片。若是，选择 960p 代理并等当前素材代理完成；仍然卡顿时，暂停后台分析或避免同时预览原片。代理生成期间 CPU 占用高属于正常现象。

6AI 分析

6.1 页面名称与入口

页面标题是“素材分析”，代码位置为 mixcut/ui/analyze_page.py。分析页没有“开始分析”按钮，启动入口只在素材库的“分析选中”。分析页提供暂停/继续和停止。

6.2 三档模式

模式抽帧判废阈值适合
快速分析3 帧0.66长素材初筛，速度快
中度分析（默认）6 帧0.5常规混剪
严格分析12 帧0.34高质量片、关键镜头

6.3 统计卡片与进度

顶部统计卡片显示素材数、已分析数、可用片段数和判废数。进度条按当前素材推进，不保证总耗时线性。

6.4 暂停与停止

暂停会停止继续抽帧，已经完成的片段保留；继续后从断点接着跑。停止会结束当前批次，未完成的素材不再继续。

6.5 片段卡片

每个片段显示时间码、时长、评分和缩略图。右键可以把片段“加入”或“排除”。加入表示允许进入混剪候选，排除表示本次不使用。

6.6 完成条件

素材的所有待分析区间都处理完，且片段结果写入分析缓存，才算完成。中途关闭软件不会丢失已完成素材的结果，重新打开工程后可继续。

6.7 切模式增量补齐

从快速切到中度或严格时，程序只补做不足的部分，不把已完成结果全部重跑。片段按 5 秒分段，片段 ID 保持稳定，便于工程恢复后继续引用。

6.8 性能建议

  • 批量分析时不要同时预览 4K 原片。
  • 需要边分析边看素材时，先给素材生成 960p 代理。
  • 分析期间 CPU 高是正常的：解码、缩放、色彩转换主要落在 CPU。
  • 机器性能有限时，先用快速模式初筛，再对重点素材跑严格模式。

7参数设置

7.1 基础参数

基础参数决定输出草稿的整体形态：成片时长、片段数量、画布比例、目标版本数。参数改动只影响下一次任务，不回改已完成草稿。

7.2 重复、时长、版本与卡点

参数作用建议
重复度控制同一素材或相似镜头被重复使用的程度先严后松，避免成片雷同
片段时长单段最短/最长时长短视频 1.5–4 秒起
版本数一次生成几条不同时间线先 1 条验证，再批量
卡点按音乐节拍对齐切点先有可用的配乐再开

7.3 五个开关

界面上的五个开关分别控制筛选、废镜头、配乐、卡点和转场等链路。关闭某个开关时，对应逻辑不参与本次生成；不要把“关闭”理解为“恢复默认”。

7.4 筛选引擎

筛选引擎按评分、时长、重复度、黑名单和可用状态筛片段。严格模式分析出的片段更适合高质量任务，快速模式适合先跑通流程。

7.5 废镜头

废镜头规则用于排除明显不可用片段，例如过暗、过亮、严重模糊、静止或命中黑名单关键词的镜头。阈值过高会误删可用镜头，过低会放进废片。

7.6 配乐、卡点与闪避

  • 配乐：选择音频文件或目录，任务生成时加入草稿。
  • 卡点：按节拍对齐切点；没有节拍数据时退化为普通切点。
  • 闪避：人声出现时降低配乐音量；需要音频分析结果。

7.7 转场与黑名单

实际规则是：短于短镜头阈值，或命中黑名单关键词的切点，一律硬切；其余切点叠化。long_threshold 当前未被实际使用，不要理解为“长于阈值必叠化”。

7.8 草稿位置

草稿目录默认自动探测剪映草稿目录，可在设置页手动改。生成前确认目录存在且剪映能读取。

7.9 “取消”的真实含义

参数页的“取消”是取消正在运行的混剪任务，不是把参数恢复默认。恢复默认请用“恢复默认”按钮。

7.10 起步参数

第一次使用建议：时长 30 秒、版本 1、重复度中高、片段 1.5–4 秒、卡点关闭、转场默认。跑通并检查草稿后再逐项放开。

8任务中心

8.1 页面结构

任务中心由任务队列、当前任务进度、输出区和日志组成。它既是启动入口，也是失败排查的第一现场。

8.2 两个启动入口

可以从参数页启动，也可以从任务中心启动全流程。两个入口使用同一套任务队列，重复点击不会并行生成同一个任务。

8.3 四个阶段

阶段做什么卡住时看什么
准备素材检查素材可用性、路径和分析结果素材是否缺失、分析是否完成
生成时间线按参数筛选片段并排时间线片段数量、重复度、卡点
渲染片段生成草稿需要的片段与转场FFmpeg 日志、磁盘空间
写入草稿写入剪映草稿目录草稿目录权限、剪映是否占用

8.4 导出摘要与输出区

任务完成后输出区给出草稿名称、路径、片段数和时长。先看摘要，再去剪映打开对应草稿。

8.5 任务队列

多版本任务会进入队列顺序执行。队列中的任务可以暂停、取消；取消只终止未完成部分，不删除已经写好的草稿。

8.6 日志

日志按阶段记录关键动作和错误。排查时先复制第一条错误，而不是只看最后一行“失败”。

8.7 状态对照

状态含义可做的操作
排队中等待前一个任务等待或取消
运行中正在准备、生成或渲染暂停/取消
已暂停保留进度，等待继续继续或取消
已完成草稿已写入打开输出目录
失败某阶段报错看日志、修复后重跑

8.8 导入剪映

任务完成后到剪映“草稿”列表找到对应工程。若没有出现，先在设置页确认草稿目录，再点任务中心的“打开输出目录”。

9设置

9.1 顶部操作

设置页顶部提供新建工程、打开工程、保存工程和重新检测。重新检测会刷新运行环境与后台组件状态。

9.2 外观

可选石墨深色、深空黑、暖灰三种主题，以及白、紫、蓝、绿强调色；点选立即生效并记住。

9.3 动效

页面切换、按钮反馈、数字滚动和动效降级都可以单独开关。系统开启“减弱动态效果”时，程序会跟随降级。

9.4 快捷键卡片

设置页只展示最常用的五组快捷键，完整列表见本手册第 10 章。

9.5 运行环境

自动读取显卡型号与 CUDA 版本、当前预览分辨率、素材色彩位深和剪映草稿目录。没有 NVIDIA 显卡时显示 CPU 软解。

9.6 缓存与草稿

显示草稿数量、缓存占用和清理策略。缓存默认写在程序目录的 cache；安装目录不可写时回退到 %LOCALAPPDATA%\MixCut\cache。代理缓存在 cache/proxy。

9.7 清理策略

默认保留最近 7 天，点击在 3 / 7 / 14 天之间循环，上限 14 天。只清理 cache 下超过天数的文件，不碰素材和草稿。

9.8 用户手册与操作指南

“缓存与草稿”卡片下方有两个独立按钮：用户手册打开本手册，操作指南打开从导入到出片的快速步骤。两份文档随程序分发，用默认浏览器打开，不依赖 Word。

11代理、解码与性能

11.1 为什么 4K 10-bit 4:2:2 会卡

这类素材的软件解码、缩放和 10-bit 转换都落在 CPU。即使显卡支持 NVENC，NVENC 只负责编码，不承担整条解码链。预览窗口同时播放原片时，解码线程会被占满，表现就是慢放、掉帧或全屏无响应。

11.2 代理规格

HEVC Main10、yuv420p10le、目标高度 960；4K 16:9 输出约 1706×960；保持原帧率和时长，音轨 AAC 192k，GOP 12。

11.3 编码器探测与降级

程序启动代理任务时先真实试编码：NVENC 可用则用硬件编码，不可用则尝试 QSV、AMF，最后退回 libx265。编码器不可用不会让任务失败，而是自动降级。

11.4 缓存

代理文件按原片路径与指纹建立 JSON 索引；源文件变化或代理版本升级会让旧代理失效。代理任务支持重复生成检查，已存在的有效代理不会重复转码。

11.5 三路解码

同时发生“AI 分析抽帧 + 预览原片 + 代理生成”时，三路解码会争抢 CPU。软件不会自动阻止分析时预览原片；建议暂停分析，或只预览已经生成代理的素材。

11.6 Qt 与 HEVC Main10

当前打包环境为 Qt 6.12，已验证 HEVC Main10 代理可正常播放。若代理仍无法播放，先确认代理文件存在且 ffprobe 能读出编码，再检查系统解码组件。

11.7 硬件建议

  • 4K 10-bit 4:2:2 素材：优先 960p 代理，避免同时跑分析与原片预览。
  • CPU 10 核以上、32 GB 内存更适合批量分析。
  • 代理缓存单独放一块读写稳定的 SSD。
  • 不要为了追求“全原片预览”关闭代理后再批量分析。

11.8 排查表

现象优先检查处理
预览像慢放原片编码、是否 10-bit 4:2:2切 960p 代理，等当前素材就绪
全屏卡死是否同时分析、代理是否生成中退出全屏，暂停分析，改用代理
代理一直不出现代理队列、缓存目录权限看日志与 cache/proxy
CPU 100%是否三路解码并发减少并发，等待代理完成

12常见问题与故障排除

12.1 启动与安装

双击无反应：确认是 64 位 Windows；查看安装目录是否完整；被杀毒软件拦截时先加白名单。
提示缺少 DLL：不要单独拷 exe，使用完整安装包；安装版的运行库在程序目录内。

12.2 素材库

导入后没有画面：先检查文件是否可播放，再看日志里的解码错误。
只选一个却分析了全部：见 4.5，确认勾选和当前文件夹。
移除后原片还在：这是设计行为，移除只删库内引用。

12.3 预览与播放

有声音没画面：切换代理档位，确认当前素材代理完成。
全屏不能用：先在窗口模式确认能播放；全屏卡顿时暂停后台任务。
预览卡但导出正常：代理只影响预览，导出仍用原片。

12.4 AI 分析

分析页不能开始：分析只能从素材库“分析选中”启动。
进度不动：看是否暂停、是否素材不可读、是否磁盘写满。
片段重复：切换更严格的重复度，或先清理重复素材。

12.5 参数与任务

点“取消”后参数没变：取消的是任务，不是参数；恢复默认用“恢复默认”。
任务卡在渲染：看 FFmpeg 日志、磁盘空间和素材路径。
没有生成草稿：确认草稿目录可写，剪映没有占用同名工程。

12.6 工程

打开工程后空白：确认版本和文件完整性，尝试 .bak。
素材丢失：路径变化或素材被移动；重新定位后再保存。

12.7 剪映

草稿列表没有新工程：设置页确认草稿目录；任务中心打开输出目录；重启剪映刷新列表。
草稿能打开但缺素材：草稿引用原路径，素材被移动后需要重新链接。

12.8 设置与缓存

缓存占满磁盘：把清理策略改为 3 天，或手动清理 cache；不要删素材目录。
设置不保存：检查配置目录写权限；安装目录不可写时程序会回退到用户目录。

12.9 可选组件

OpenCLIP 模型用于语义能力，缺失时相关功能不可用，但不影响基础分析。安装包不包含工程根下的 OpenCLIP 目录；需要时按程序提示单独放置。

12.10 信息收集清单

反馈问题请附：Windows 版本、显卡与驱动、素材编码与分辨率、复现步骤、任务中心日志、是否使用代理、工程文件版本。不要只发一张报错截图。

13典型工作流

13.1 快速出 30 秒

  1. 导入 10–20 条素材，建一个文件夹。
  2. 快速分析，等统计卡片出现可用片段。
  3. 参数设 30 秒、1 个版本、片段 1.5–3 秒。
  4. 任务中心启动，完成后到剪映检查。

13.2 4K 高质量

  1. 先给素材生成 960p 代理，确认预览流畅。
  2. 严格分析，避免同时预览原片。
  3. 提高重复度约束，片段 2–4 秒，开卡点。
  4. 生成 1 个版本，逐段检查后再批量。

13.3 多版本

先用 1 个版本验证参数，再改成 3–5 个版本排队。版本之间共享素材与分析结果，不重复分析。

13.4 精筛

在分析页右键排除不可用片段，再回参数页收紧时长和评分。精筛后片段数变少是正常的，不要为了凑时长放宽到废片。

13.5 归档与换机

保存工程，记录素材根目录；把工程和素材一起迁移，保持路径；打开后先检查素材有效性再继续任务。

13.6 出片检查

检查片头片尾、重复镜头、黑帧、音量突变、字幕位置和总时长。MixCut 生成的是草稿，最终导出前仍要人工确认。
