# MixCut Studio 4.0

Windows 桌面版智能混剪工具（Python + PySide6）。在自动粗剪、配乐卡点、规则化转场之外，新增基于 **Remotion** 的全自动成片引擎，并在每个工作界面加入**素材选择框架**。粗剪与混剪输出可在剪映中继续二次编辑的**工程文件**（剪映草稿 + MixCut 时间轴 JSON），全自动直接输出 mp4。

## 四个页面

### 1. 素材与参数
- 添加多个视频，或递归扫描素材文件夹
- 素材检查 / 确认锁定 / 视频预览
- 选择输出目录与输出分辨率（4K / 2K / 1080p / 720p，默认 1080p，竖屏 9:16）
- **右下角“详细参数”面板**：点击/预览哪个视频，就显示该视频的分辨率、帧率、编码、像素格式、时长、码率、音频流与文件大小

### 2. 顺序粗剪（第一个工作界面：保持导入顺序）
自动识别并剔除废镜头，**严格保持导入顺序、不做重排**：
- 黑屏检测（blackdetect）
- 静止画面检测（freezedetect，覆盖长时间不动 / 对墙 / 虚焦近似）
- 静音 / 空音频检测（silencedetect，无音轨素材整段视为空音频）
- 画面检测与静音检测各自独立开关，黑屏/静止可细分开关，阈值可调
- 分析后在审核表逐条勾选废镜头，取消勾选即可保留
- 生成统一时间轴（`mixcut_timeline.json`）并落地为剪映可编辑工程

### 3. 智能混剪（第二个工作界面：随机混剪 + 配乐 + 转场）
- 顶部左右两栏：左侧“素材选择”勾选要混剪的视频，右侧“素材库 · 参数配置”放置混剪基础参数（仅此页面为左右布局）
- 先剔除废镜头，再在有效段内随机取片，可随机排列 / 允许重复 / 设置单段长短
- **生成工程数**：一次生成 N 个独立的剪映工程草稿，每个工程随机排列不同、各自按目标时长/片段长短装配；废镜头检测只做一次，N 个工程复用，不重复跑
- **分析结果缓存**：同一份素材 + 同一套检测参数的分析结果在运行期间缓存，改混剪参数（目标时长/片段长短/工程数/随机排列等）重新生成时直接复用、不重复分析；只有更换素材或改动检测开关才重新分析。纯内存缓存，关闭软件即自动删除
- **清晰度 / 帧率**：参数区可选清晰度 360p→8K（竖屏 9:16）、帧率 24/25/30/48/50/60/100/120，直接决定草稿画布尺寸与工程帧率；素材本身分辨率不足时选再高也不会增加细节
- **草稿位置**：右侧“草稿位置”可选择自定义输出文件夹，草稿直接落到该目录，方便打包传给别人；留空则保存到剪映默认草稿目录
- **目标时长为大概值**：用“时长浮动 ±”给出容差，成片落在 目标±浮动 范围内即停止，末段保持自然长度，不再硬凑到精确秒数
- **配乐方式**：手动选择 BGM / 本地随机配乐（指定音乐文件夹，每次随机挑一首）/ 云端随机（暂未开放，选中后不加载音乐）
- 自动配乐：librosa 节拍检测给出 BPM 与鼓点，开启卡点后切点直接对齐鼓点
- 随机排列已加强：每轮重新洗牌并保证拼接处不出现相邻重复，各素材覆盖更均匀
- 音频闪避（ducking）：检测到人声时自动压低 BGM，人声结束恢复（基于能量的轻量人声判断，音量可调）
- 规则化转场：短镜头硬切 / 闪切，长镜头叠化淡变；可设置黑名单（逗号分隔分类名，如“产品特写”），命中的片段之间只硬切

## 窗口与浏览方式
- 每个页面内容固定宽度、居中显示，放大到全屏不会拉伸控件；内容超出高度时像网页一样上下滚动浏览
- 窗口可自由上下、左右缩小（最小约 820×560），缩小时通过滚动查看而不是挤压界面
- 数字框 / 下拉框在未点击聚焦时忽略滚轮，滚动页面不会误改参数；点进控件后滚轮仍可用
- 分析、渲染的子进程在后台静默运行，不会弹出黑色命令窗口
- 混剪 / 全自动点“取消”后会自动恢复开始按钮，可直接再次开始；主动取消不会误报错误弹窗

### 4. 全自动（Remotion 引擎，一键直接出 mp4）
- 基于 Remotion 编程式视频渲染，1080×1920 / 30fps，无需打开剪映
- 可设标题、副标题、单段时长、输出路径，自动按顺序拼接并加标题与进度条
- 输出时长按所选素材实际总时长计算
- 本地素材会自动暂存到 `remotion_engine/public/materials` 供渲染，完成后自动清理

## 素材选择框架（每个工作界面都有）
顺序粗剪、智能混剪、全自动三个工作界面顶部都有勾选式素材框架，列出第一页已确认的全部素材：
- 勾选即参与本次分析 / 生成 / 渲染，未勾选的不处理，素材多时只挑要用的
- 支持全选 / 全不选 / 反选 / **删除已选**：删除已选会把勾选的素材移出本框架（不删磁盘文件），切页刷新后仍保持删除；各页面的删除互不影响，回到第一页重新“确定使用”会全部恢复
- 切换页面或重新确认素材后自动同步，并保留已有勾选

## 工程格式
- 剪映草稿：自动保存到剪映草稿目录（`AppData\Local\JianyingPro\User Data\Projects\com.lveditor.draft`），目录内含 `draft_content.json`、`draft_meta_info.json` 与 `mixcut_timeline.json`
- MixCut 时间轴 JSON 是自家中间工程，可重新加载继续调整

> 分辨率说明：画布尺寸决定剪映导出分辨率。选 4K / 2K 只有在素材本身达到该分辨率时才有真实细节；1080p 素材选 4K 只会被放大，文件更大更慢。

## 环境要求
- Windows 10/11
- Python 3.14（依赖：PySide6 6.12、pyJianYingDraft 0.3.1、librosa 1.0、soundfile 0.14，及随附的 numpy / scipy / numba）
- 全自动（Remotion）需要 Node.js（已在 v22 验证），并保留 `remotion_engine` 文件夹（含 `node_modules`）；首次渲染会自动下载 Chrome Headless Shell，之后不再重复下载
- 程序不依赖 node 在 PATH：会按 `MIXCUT_NODE` 环境变量 → PATH → 常见安装目录 → Doubao 运行时的顺序自动定位 node.exe；双击启动（PATH 里没有 node）也能渲染

## 从源码启动
```bat
启动MixCut.bat
```
或命令行：
```bat
py -3.14 main.py
```
> 注意：请用 `py -3.14`，系统 PATH 里的 `python` 可能指向未装依赖的其他版本。

## 打包 EXE
1. 确认 `ffmpeg-20200831-4a11a6f-win64-static\bin\` 下有 `ffmpeg.exe` 和 `ffprobe.exe`（已自带）。
2. 双击 `build_windows.bat`。
3. 构建成功后运行 `dist\MixCutStudio\MixCutStudio.exe`；分发时复制整个 `dist\MixCutStudio` 文件夹，不要只复制 exe。
4. 要让打包版支持全自动，需把 `remotion_engine` 整个文件夹放到 `MixCutStudio.exe` 同级目录，并确保目标机器装有 Node.js；在项目 `dist` 内运行时会自动复用项目根目录的 `remotion_engine`。

## 常见问题
- 草稿在剪映里不显示/打不开：确认草稿文件夹内有 `draft_content.json` 和 `draft_meta_info.json`。
- 素材提示无效：素材需为 mp4 / mov / mkv / m4v / avi / webm 且文件非空。
- 闪避不灵敏：人声判断基于能量，环境嘈杂或人声很轻时可在界面调整，必要时可关闭闪避手动处理。
